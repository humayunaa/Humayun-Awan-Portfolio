# Instructions on how to use the Flask Film Review Web Page

- Access this repository in your terminal (e.g. ubuntu/linux/wsl)
- Do this using: cd repo_name (if its in a folder you must be in that folder first using: cd folder_name)
- Go to the src/flask folder in your terminal
- Do this using: cd src/flask
- In your command line input: python3 app.py
- On a web browswer (e.g. google chrome) open [http://127.0.0.1:5001/](http://127.0.0.1:5001/) in your URL
- You should now see the web page
- To close the web page press: CTRL + c in your terminal
